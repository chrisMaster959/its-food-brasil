# Its Food Brasil

Requisito: .NET 8 SDK.

    dotnet run

Abre em http://localhost:5080 (Dashboard). A tela principal é Financeiro > Fluxo de Caixa.
Os ícones usam Bootstrap Icons via CDN (precisa de internet).
Os dados do Fluxo de Caixa são de exemplo, definidos em Controllers/FinanceiroController.cs.
